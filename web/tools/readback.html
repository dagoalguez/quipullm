GPU readback and upload timing

Experiment for streaming MoE experts from disk. It loads no model. It measures, on THIS browser and GPU: (1) how long it takes to ask the GPU for a small result and wait for it (an engine that streams experts has to do that in every MoE layer to learn which experts were chosen), and (2) how fast data can be copied from the page into GPU memory. Close other heavy programs first; run it twice.
